# CMSC203_Assignment3
CMSC203_Assignment3 - Cryptography, decoding using three methods; Vigenère, Playfair, and Caesar
Course: CMSC203 - Computer Science
Instructor: Ahmed Tarek
Student: Luis Aguero
Due Date: 10/15/2026

Projected Description
This project implements three classical encryption and decryption methods in Java:
- Vigenère Cipher: Uses a repeating keyword to encrypt and decrypt text.
- Playfair Cipher: Encrypts pairs of characters using a matrix generated from a keyword.
- Caesar Cipher: Shifts characters by a specified numerical key.

Technologies Uses
- Java
- Eclipse IDE
- JavaFX for the graphical user interface
- JUnit for testing

Source Files
- CryptoManager.java: Contains the encryption, decryption, and string validation methods.
- CryptoManagerTestStudent.java: Contains student-written JUnit tests.

Testing
The project includes JUnit tests for validating string bounds and checking the encryption and decryption methods. The JavaFX interface can also be used to test each cipher interactively.
